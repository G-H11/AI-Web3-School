### 📺 晚间 Workshop（19:09）: Darwin — AI Agent 时代重新审视区块链技术选择 & 开发实战

> 完整笔记：[notes/2026-06-05 AI Agent 时代重新审视区块链技术选择与开发实战.md](notes/2026-06-05%20AI%20Agent%20时代重新审视区块链技术选择与开发实战.md)

**关键收获**：
1. **成本-收益临界点框架**：AI Agent 同时在压低成本（基础设施改善 + Agent 承担用户教育/开发复杂度）和放大收益（跨主体 Agent 交互天然需要区块链作为中立协调层）
2. **本质复杂性 vs 附属复杂性**（Brooks No Silver Bullet）：SafeAgent Wallet 的权限边界是"本质复杂性"（必须人工确定），Policy Engine 的代码实现是"附属复杂性"（可委托 AI）
3. **五步开发流程**：需求确认（PRD + Issues 垂直切片）→ 实现（Roughloop 模式）→ 调试（Computer Use 闭环验证）→ 部署 → 升级
4. **Implementation Notes 概念**：让 Agent 记录自行做出的设计决策 → 直接对应 SafeAgent Wallet 的 AuditLogger 思路
5. **Roughloop**：每个子任务用全新上下文的 Agent 执行 → 避免上下文污染，提升质量

**对 SafeAgent Wallet MVP 的启发**：
- 参考五步流程加速 MVP 开发
- AuditLogger = Agent 自行决策的"Implementation Notes" 上链版
- Policy Engine 规则确认是本质复杂度 → G-H11 必须亲自定义
