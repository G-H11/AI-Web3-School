### 关键概念

- **Hackathon 策略聚焦**：有限时间内的取舍比技术能力更重要。双线推进在 7 天内不可行 → 果断砍掉一个方向
- **Zai 赛道差异化**：z.ai 的核心价值在 AI 深度集成（Function Calling），而非合约复杂度。Vinothèque 的 AI 侍酒师比 SafeAgent Wallet 更适合 Zai 赛道
- **从通用到具体**：原 NFT DApp 是「通用 NFT 馆藏」，Vinothèque 是「酒业 NFT 吧台」——垂直场景能讲出更清晰的叙事
- **Phase 0 价值**：详细规划设计虽然不产出代码，但 533 行的 VINOTHEQUE_PLAN.md 让接下来 6 天的编码可以「按图施工」，大幅降低返工风险

### 遇到的问题

- ⚠️ **方向焦虑**：原双线策略导致每天 task list 很长但推进缓慢，需要决策
- ⚠️ **Zai 赛道调研不足**：需要亲自注册 z.ai 并测试 API 才能确认 Function Calling 能力

### 解决方案 / 理解

- ✅ 做出硬决策：砍掉双线，all-in Vinothèque。SafeAgent Wallet 归档到 Week 4
- ✅ 详细规划替代盲目编码：用 2h 规划设计换来清晰的 7 天路线图
- 🔜 明日首要任务：Scaffold-ETH-2 初始化 + z.ai API Key 获取 + Function Calling 测试
