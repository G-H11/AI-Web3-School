## Handbook 学习路径

### 最小路径（必读）⏱ ~30min
<!-- Week 1 基础补齐：Web3 核心概念 -->

- [Cryptography（密码学）](https://aiweb3.school/zh/handbook/web3/cryptography/)
  - 哈希、公私钥、签名 — Agent Wallet 的底层安全原语
  - 你对签名机制已有了解，重点看 ECDSA 和 Smart Account 签名差异
- [Smart Contract（智能合约）](https://aiweb3.school/zh/handbook/web3/smart-contract/)
  - 链上规则如何部署、调用、更新状态 — 理解 Cobo CAW 合约接口的基础
  - 你有 Solidity 经验，快速扫读 + 关注 Account Abstraction 相关合约模式

### 推荐路径（建议）⏱ ~1h
<!-- Hackathon 启动日必备准备 -->

- [Security（Web3 安全）](https://aiweb3.school/zh/handbook/web3/security/)
  - 合约安全、权限风险、模拟与监控 — SafeAgent Wallet 必须覆盖的维度
  - 与已有 Threat Model 对照，补充 Web3 特有的安全边界
- [AI Security（AI 安全）](https://aiweb3.school/zh/handbook/bridge/ai-security/)
  - Prompt Injection、工具滥用、权限隔离 — SafeAgent Wallet 的核心差异化
  - 结合 Agent Wallet 权限策略七维度做对照检查
- **Hackathon 实战启动：**
  - [ ] 打开 Cobo Agentic Wallet 文档，确认 SDK 接口和 demo
  - [ ] 基于 5/28 架构设计搭建 SafeAgent Wallet MVP 项目骨架（目录结构 + README）
  - [ ] 将 MVP 代码放入 `demos/safeagent-wallet/`

### 挑战路径（选做）⏱ ~1h+
<!-- 深度 Hackathon 技术准备 -->

- [DeFi（去中心化金融）](https://aiweb3.school/zh/handbook/web3/defi/)
  - 理解资产、流动性、借贷和风险传播 — Agent 支付场景的经济模型基础
- [Indexing（链上索引）](https://aiweb3.school/zh/handbook/web3/indexing/)
  - 链上事件 → AI 可用数据层 — SafeAgent Wallet 的交易监控数据源
- **Hackathon Proposal 完善：**
  - [ ] 输出最终版 Project Proposal（问题定义 → 方案 → MVP 范围 → 技术栈）
  - [ ] 确认 Cobo 赛道提交要求（demo 视频、代码仓库、文档）
- [Verifiable AI（可验证 AI）](https://aiweb3.school/zh/handbook/bridge/verifiable-ai/)
  - Agent 决策如何被验证和审计 — Hackathon 项目的可信度加分项
