### Hackathon 方向选择分析

**候选方向：SafeAgent Wallet — AI Agent 链上权限与支付管理**

**方案 A：Track 1 — Cobo Agent Economy**
- ✅ 契合点：Agent Wallet 天然属于 Agent Economy 生态（支付、结算、权限）
- ✅ Cobo 有明确的 Agentic Wallet 基础设施，可直接集成
- ⚠️ 需在 Cobo 框架内做项目，灵活性受限
- 💰 有奖金资格

**方案 B：Track 2 — ZAI 开放赛道**
- ✅ 开放度高，只需调用 ZAI 大模型即可
- ✅ SafeAgent Wallet 可以自由发挥架构设计
- ⚠️ Agent Wallet 更偏 infra，可能不如消费级应用有展示力
- 💰 有奖金资格

**初步倾向：Track 1（Cobo Agent Economy）**
理由：SafeAgent Wallet 的核心是 Agent 支付与权限管理，与 Cobo Agentic Wallet 方向高度一致。在 Cobo 框架内开发反而能借助其成熟的账户抽象基础设施，聚焦差异化（AI 驱动的权限策略引擎）。

### 关键概念

- **Chain-aware Context**：链上状态 → Agent 上下文的桥梁，核心挑战是数据新鲜度、Gas 成本和状态一致性
- **Web3 Tool Use**：Agent 调用链上工具的模式——RPC 查询、交易构造、签名授权
- **Human-in-the-loop**：Agent 自动化与人工审核的边界设计——Hackathon MVP 的核心交互模式
