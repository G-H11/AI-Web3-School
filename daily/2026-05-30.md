## Handbook 学习路径

### 最小路径（必读）⏱ ~30min
<!-- 周末必做：回顾本周核心内容，锁定 Hackathon 方向 -->

- [Account Abstraction（账户抽象）](https://aiweb3.school/zh/handbook/web3/account-abstraction/)
  - 回顾 ERC-4337 UserOperation 生命周期、Bundler、Paymaster——SafeAgent Wallet 的底层基础设施
- [Agent Wallet（Agent 钱包）](https://aiweb3.school/zh/handbook/bridge/agent-wallet/)
  - Hackathon 视角重读：哪些权限设计是 MVP 必须的，哪些可以放到 stretch goal

### 推荐路径（建议）⏱ ~1h
<!-- 周末深化：补齐技术短板，服务 Hackathon 开发 -->

- [Wallet / Permission 赛道页](https://aiweb3.school/zh/handbook/tracks/wallet-permission/)
  - 了解赛道期望产出和参考原型——SafeAgent Wallet 对标定位
- [Machine Payment（机器支付）](https://aiweb3.school/zh/handbook/bridge/machine-payment/)
  - Agent 如何发起支付、管理额度、处理退款——Agent Economy 赛道的核心
- [Agent Workflow（Agent 工作流）](https://aiweb3.school/zh/handbook/bridge/agent-workflow/)
  - Human-in-the-loop 设计——SafeAgent Wallet 的关键交互模式

### 挑战路径（选做）⏱ ~30min+
<!-- 有余力：提前启动 Hackathon 技术预研 -->

- 实战：搭建 SafeAgent Wallet MVP 技术验证
  - 用 Safe{Core} SDK 完成一个最简单的 UserOperation 签名→发送→确认流程
  - 如果符合 Track 1（Cobo）：预研 Cobo Agentic Wallet API 集成方式
  - 如果符合 Track 2（ZAI）：预研 ZAI 大模型调用方式
- [Agentic Commerce（智能体商业）](https://aiweb3.school/zh/handbook/tracks/agentic-commerce/)
  - 了解 Agent Economy 赛道全景，理解 SafeAgent Wallet 在 Agent 支付生态中的定位
