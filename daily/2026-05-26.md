## Handbook 学习路径

### 最小路径（必读）⏱ ~30min
<!-- 今天必须完成的核心：Bridge 入口章节 -->

- [Chain-aware Context（链感知上下文）](https://aiweb3.school/zh/handbook/bridge/chain-aware-context/)
  - 链上状态如何进入 Agent 上下文？这是所有交叉应用的起点
- [Web3 Tool Use](https://aiweb3.school/zh/handbook/bridge/web3-tool-use/)
  - RPC、钱包、合约工具如何被 Agent 调用——这决定了 Agent 能在链上做什么
- [Agent Workflow](https://aiweb3.school/zh/handbook/bridge/agent-workflow/)
  - 哪些步骤适合自动化，哪些必须 human-in-the-loop

### 推荐路径（建议）⏱ ~1h
<!-- 深入交叉核心问题 -->

- [Agent Wallet](https://aiweb3.school/zh/handbook/bridge/agent-wallet/)
  - Agent 能拿什么权限？如何限制和撤销？Week 2 核心议题
- [Machine Payment](https://aiweb3.school/zh/handbook/bridge/machine-payment/)
  - 机器之间如何完成小额支付和服务结算
- [Agent Identity](https://aiweb3.school/zh/handbook/bridge/agent-identity/)
  - Agent 如何被识别、授权和追踪责任边界
- 🧭 **赛道初探**：浏览 [前沿探索](https://aiweb3.school/zh/handbook/#前沿探索) 5 个赛道简介，标记感兴趣的

### 挑战路径（选做）⏱ ~30min+
<!-- 方向选择：挑一个赛道深挖 -->

从以下赛道中选 1 个精读（根据你的背景：AI+Web3 中级、偏开发）：

- [Agentic Commerce（智能体商业）](https://aiweb3.school/zh/handbook/tracks/agentic-commerce/)
  - Agent 发现服务 → 协商任务 → 完成支付 → 留下凭证
- [Wallet / Permission（钱包与权限）](https://aiweb3.school/zh/handbook/tracks/wallet-permission/)
  - Session Key、Policy、Guard——给 Agent 配一把"能收回的钥匙"
- [Dev Tooling（开发工具）](https://aiweb3.school/zh/handbook/tracks/dev-tooling/)
  - 面向合约理解、测试、文档的 AI 工具——和你日常开发最相关
