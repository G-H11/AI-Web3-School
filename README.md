# AI × Web3 School 学习仓库

## 简介
**AI × Web3 School** 是一个专注于人工智能与去中心化技术融合的学习社区。我们致力于帮助开发者从零开始，深入理解 AI 与 Web3 的基础知识、开发工具和最佳实践，探索智能合约、链上 AI Agent、去中心化算力等前沿方向。
