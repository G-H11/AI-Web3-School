## 核心观点：Network is Everything

> 人脉即分发（Network is Distribution）。以 Facebook 为例，扎克伯格先在大学测试，再扩展到全美大学，网络是分发的根基。

在 AI × Web3 领域，技术变化极快——一个月前学的可能已被颠覆。**唯一不变的是你的个人品牌、经验积累和人脉网络**。

## Builder 成长路径

```
Onboarding（入门）→ Learning（学习）→ Contributing（贡献）→ Becoming a Builder（成为构建者）→ Founder（创始人）
```

关键心态：
- **不要一进来就找工作**。市场饱和，尤其非美国地区更卷
- 目标应该是成为 Builder，做自己的项目、创建自己的 startup
- 学习后**立刻去贡献**——不要只学不练

## 实操建议：如何建立你的网络

### 1. 学好英语 🔑
- **整个生态是英文主导的**。只停留在中文圈会关闭大量机会
- Anton 自身经历：从只说法语 → 英语，机会「好了 100%」
- 建议：看美剧、投入 1-2 个月跟老师直播练习

### 2. 用 X（Twitter），不是 LinkedIn
- LinkedIn 偏商务，Builder 的东西全在 X 上
- 用法完全不同——不要像用 LinkedIn 那样用 X
- 策略：**先关注对的人 → 再创造内容吸引关注**
  - 发特定领域内容（如 DeFi），该领域的人会自然关注你
  - 形成圈层效应

### 3. 加入与你身份/兴趣匹配的社群
- 你是女性 → 加入 Women in Web3 社群
- 你是学生 → 加入 Student Builder 群组
- 已有社群身份背书，求助更容易得到回应
- 中文社区是你的 super power

### 4. 参与开源贡献
- **招聘官现在看 GitHub，不是 LinkedIn**
- 开源 24/7 开放，性格内向也能按自己节奏贡献
- 深入贡献某个项目 → 项目方会主动 tap 你（你已熟悉代码库）
- 是打开工作大门的最佳路径

### 5. 成为 Speaker / Mentor / Volunteer
- 从本地 Meetup 开始做分享 → 积累公信力
- 做 Hackathon Mentor（Anton 自己常做）
- 在国际会议做志愿者——帮助克服害羞，建立全球人脉
- 路径：**Local → National → Global**

### 6. Build in Public
- 公开构建过程，展示项目进展
- 案例：Diana 被裁员后，靠 Build in Public 拿到 WalletConnect 的工作

### 7. 参与国际活动
- 积累的全球人脉 5 年后依然有效——「5 年后发条消息说我们在 DEF CON 见过」

## Q&A 精华

### Q1: 如果今天重选方向，AI、Web3 还是 AI+Web3？
**A:** AI+Web3。Web3 让你无门槛构建——不需要依赖闭源平台，可以自由组合协议模块。AI 加速一切。未来十年关键的是 **Agent Economy**——Agent 可能比人类更频繁地使用 Web3。

### Q2: 早期 Builder 如何做个人品牌？
**A:** 
1. 加入有 mentor 体系的社区项目
2. 做项目 → 被合作方看见 → GitHub 丰富起来
3. 持续贡献开源

### Q3: 冷联系陌生人对方不回复怎么办？
**A:**
- 如果你们有**共同联系人（mutual connections）**，对方查看你 X 主页会发现你们有共同好友圈 → 降低戒备
- 通过社群内部联系比外部冷触达有效得多
- 也可以尝试 Discord、项目社区等渠道

### Q4: 艺术背景想做全栈 Builder，缺乏工程直觉怎么办？
**A:**
- 善用 Vibe Coding 工具（Claude、Cursor），加载设计类 skill
- 设计师背景反而是优势——最好看的应用都是有真正设计师参与的
- 加入 Figma 等设计 skill 到你的 AI 工具链中
- Solana 生态有很好的 Vibe Coding 工具
