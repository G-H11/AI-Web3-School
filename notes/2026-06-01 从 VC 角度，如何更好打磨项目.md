## 核心内容

### 1. AI 时代的创业成本变化

- AI 工具（Codex, Gemini 等）让一人公司成为可能，顶级架构师一人可顶十几人
- 创业门槛大幅降低，小团队灵活优势凸显：一两周做出 MVP → 快速验证 → 规模化扩展
- 成本降低 → 竞争更激烈 → **Timing 和执行力成为关键差异化因素**

### 2. VC 投资标准的务实转变

| 旧标准 | 新标准 |
|--------|--------|
| PPT + Narrative 融资 | 需要实打实的数据：用户数、商业闭环、盈利 |
| 看概念和叙事 | 先看项目是否真的落地 |
| 讲故事就能拿钱 | 获客成本、盈利模式、增长数据必须验证 |

**VC 现在会问的问题：**
- 你有用户吗？
- 你有商业闭环吗？
- 用户增长怎么样？
- 你对市场的理解是什么？
- 获客渠道和成本是什么？

### 3. Timing 的力量 — Myshell 案例

- Myshell 创始人 AI 行业深耕十年
- 大模型出现时，做了一个简单的 Telegram Bot（英语口语练习）
- 一周 1.2 万用户（Web3 标准下很大）
- 创始人坦诚：没有任何技术壁垒，唯一的优势是十年积累 → **比其他人更快抓住机会**
- 结果：Tracy 因 2000 万估值觉得贵而 pass，后来 Binance 投资，估值数亿美元

**启示：** Timing + 快速执行 + 行业积累 > 纯技术壁垒

### 4. 壁垒的本质

- 大多数 AI 项目没有真正的技术壁垒（底层是大模型）
- 壁垒来自于：先发优势、忠实种子用户、行业经验、持续学习迭代
- **套壳 AI 项目（把 AI 当包装的）** VC 不会投
- 创始人需要回答：AI 模型迭代后，你的项目还有存在意义吗？

### 5. VC 眼中优秀的创始人

**基础要求：**
- 有主见但 open minded（不能一意孤行）
- 执行力强（能快速从失败中学习成长）
- 叙事能力好（能把概念落地）

**加分项：**
- **个人魅力 + 行业影响力**：Twitter 发一句话几万转发 → 节省市场费用
- **Connection 能力**：快速定位关键人脉，建立深度合作（案例：为上市所特意去读 EMBA 建立关系）
- **社区自然流量**：在 Web3 尤其珍贵
- **商业能力**：对接项目方、媒体、KOL、交易所

### 6. 融资的核心迷思

> **VC 的钱不是免费午餐，而是长期负债**

- 早期融太多钱 → 后期币价抛压大 → 丧失主动权
- 如果早期成本低（烧 token），建议 **self-funded 跑通闭环**，需要规模化时再找 VC
- VC 真正价值：**背书 + 二次传播 > 财务投资**
- 明星项目对拿 VC 钱很谨慎，先看 VC 的声望和声誉

### 7. VC 投资流程

```
Deck 提交 → Kickoff Meeting → DD (尽职调查) → Secondary Meeting
→ 内部投资说明会 (Partner 评审) → 第三次 Meeting → 协议签署
→ 法务审核 → 打款 → 投后管理
```

### 8. 投资风格分类

| 风格 | 特征 | 适用项目 |
|------|------|---------|
| 激进型 | 百倍收益 or 血本无归 | 叙事宏大但变现不清晰的基础设施 |
| 稳健型 | 亏不了太多，赚不了太多 | 已有明确盈利路径的项目 |

- 有的 VC 融了很多钱必须投出去 → 手松 → 运气好碰上就是 timing 到了
- Web3 项目生命周期大多不超过三年

### 9. Hackathon 项目评判标准

> **AI 是附加值，不是决定性因素**

Tracy 作为黑客松评委会关注：
- 项目方对行业的深度理解
- 知道行业痛点是什么
- 能说服评委、打动评委
- **AI 确实帮项目加成**（不是套壳）
- 创始人幽默风趣、有个人魅力 → 将来融资能力也会很强
- 有互补的合作伙伴是加分项

## 对 SafeAgent Wallet 的启示

1. **壁垒 = 行业理解 + 快速执行**：SafeAgent Wallet 不需要颠覆性技术，而是比别人更快地解决 Agent 权限管理的实际痛点
2. **Timing 优势**：Cobo Agentic Wallet 刚发布，Agent Economy 赛道刚开始，正是先发窗口期
3. **VC 会看什么**：实际用户（Agent）、商业闭环（支付抽成/服务费）、增长数据
4. **创始人加分项**：在 Agent Commerce/Agent Wallet 领域的持续沉淀（笔记、架构、Threat Model）就是行业积累的证明
5. **Hackathon 展示**：重点不是技术多炫，而是对 Agent 支付痛点的深度理解 + 可落地的 Demo
